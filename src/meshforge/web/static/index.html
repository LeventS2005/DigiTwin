Quick start
  1. source — pick a shape → Generate synth, or type a surface path → Load surface.
  2. Run centerline → Run wall → Run volmesh (check inverted 0).
  3. Analyze in the solve (FEA) or cfd panel.
  4. Save work file (.mfwork) → Load with replay ticked to reproduce.

Run step panels top-to-bottom; a step run before its input errors loudly in the log (harmless — run the missing one). Full guide: docs/TUTORIAL.md and docs/APP_GUIDE.md.
