meshforge Workbench

Quick start
  1. source — pick a shape → Generate synth; or starting from a file, open the matching import_* panel (e.g. import_cad for DXF/DWG) and run it first.
  2. Then Run centerline → Run wall → Run volmesh (check inverted 0).
  3. Analyze in the solve (FEA) or cfd panel.
  4. Save work file (.mfwork) → Load with replay ticked to reproduce.

Run step panels top-to-bottom; a step run before its input errors loudly (log, and next to the button). Full guide: docs/TUTORIAL.md and docs/APP_GUIDE.md.
